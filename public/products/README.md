# 产品图片放置说明

每个产品使用独立目录，例如 `public/products/on-gold-standard-whey/`。请放入品牌提供或自行合法拍摄的原始产品图，不要使用 AI 生成包装，不要重绘文字、Logo、罐体或防伪标签，也不要修改包装内容。

建议文件名：`front.webp`（正面）、`back.webp`（背面标签）、`detail-01.webp`（合法取得的细节图）。推荐正方形或 4:5 比例，最长边 1800–2400 像素。当前页面显示中性占位卡，接入图片时应为每张图补充准确的中文替代文字。

产品目录：`on-gold-standard-whey`、`on-gold-standard-isolate`、`on-hydro-whey`、`on-creatine-glutamine`、`yamamoto-iso-fuji`、`yava-labs-range`、`bpj-protein-drink`、`arla-isolate-shake`。
