黑算盘：从当前桌面记录首次复制独立手机版账本

本次范围
电脑版继续正常使用。只读备份当前产品、采购、运费配置、方案、存档和
库存/FIFO，再复制到现有管理员专用的独立手机版账本。手机版不自动
写回电脑版。不删除、重置、替换桌面记录或原服务。

只读来源
原服务旁的 abacus-readonly-export.html 使用独立外部脚本。只在点击按钮
后读取三个指定 localStorage 键，两次原始字符串完全一致才发起本地
JSON 下载。缺失键不会伪装成空对象。该文件只包含浏览器存储；完整
备份还必须包含已核验的原静态文件。两次读取不是跨键数据库事务。
原始下载、静态备份、核验报告及上传快照都保留在本机私人目录，不进入
源码仓库、构建产物、公开目录或 Library。

首次初始化
GET /abacus/initialize 为受保护的管理员页面。
POST /api/abacus/initialize 只接受现有 Snapshot 格式的完整 JSON 原始
字节：schema=1、revision=1、updatedAt、data。最大 2 MiB。上传前的
本地核验不合并测试分支，不补造缺失存储，不采用历史未批准候选。

管理员页面使用现有独立黑算盘会话，不借用官网会员会话，不创建新账号
或密码。服务端使用既有管理员配置和私有 Blob 配置；不将秘密复制到
本机、上传文件、客户端脚本或日志。只允许正式 Production，Preview
和开发环境拒绝运行初始化入口。

非秘密配置
ABACUS_ACCESS_MODE=admin
ABACUS_PUBLIC_ORIGIN=https://www.spnc.cn
ABACUS_STORAGE_ENABLED=true
ABACUS_INITIALIZATION_SHA256=<完成本地核验后那份上传快照文件的 SHA-256>

最后一项只绑定实际 POST 的完整 Snapshot 文件原始字节，不是浏览器
原始下载包装文件的摘要，也不是重排 JSON 后计算的摘要。缺失或不符
即拒绝。必须使用本次实际核验值，不能用文档示例或旧候选值。配置与
代码部署由唯一生产发布者执行，不在本地测试中自动设置。

提交、读回和故障处理
服务端先写入不可变审计回执并读回，再创建不可变版本，以条件创建的
账本 head 作为提交点。已有其他账本拒绝覆盖，普通 state 接口不能
完成首次建账。相同文件重试只能核对已完成的同一次操作，不能再次
覆盖、重置版本或回滚后续记录。每次写入前复核会话。
连接中断或 503 表示结果待核实，不能断言没有提交。只用同一已核验
文件重试并读回确认。失败可能留下未被 head 引用的不可变对象；不
自动删除它们，也不删除或回滚已提交的账本。关闭访问开关可阻止后续
访问，但不是删除数据或恢复账本。

实际启用验收
验证无会话 API 拒绝、正式管理员登录、初始化回执、快照摘要/计数、
利润/FIFO对照、刷新和手机离线只读、同步时间、断网禁写及注销清理。
管理员上传文件只保留在当前页面内存，不写入浏览器持久存储或缓存。
手机版离线快照是已成功同步副本，不能作为唯一备份。

历史文档说明
早期本地说明中“停旧入口、唯一写源、整套切换”等表述不适用于本次
已批准范围；本次是桌面保留、手机版独立账本的一次复制。
