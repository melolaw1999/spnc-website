# 淘宝开放平台接入说明

当前状态：**待淘宝授权**。`MockTaobaoOrderProvider` 已完整承担演示流程；`TaobaoOpenPlatformProvider` 只保留明确接口，不伪造调用、不抓网页、不接收用户密码或 Cookie。

正式接入步骤：申请开放平台应用和订单/退款权限；实现 OAuth 授权与安全存储；实现令牌刷新/重新授权提示；按平台规则做订单增量与单笔查询；同步退款；对消息回调验签；加入指数退避重试、幂等事件键、平台限流和权限不足提示；所有日志脱敏；对照实际授权字段重新确认订单认领方案。

环境变量仅放部署平台密钥服务：`TAOBAO_APP_KEY`、`TAOBAO_APP_SECRET`、`TAOBAO_ACCESS_TOKEN`。不得写入 Git。真实适配器接入前需核对淘宝开放平台最新官方文档和获批权限。
