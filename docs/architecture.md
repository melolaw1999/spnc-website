# 系统架构

官网采用 Next.js App Router 与 TypeScript，部署于 Vercel。公开内容在构建阶段生成，不依赖数据库、会员系统或第三方订单接口。

核心结构：

- `src/data/catalog.ts`：经过筛选的公开商品资料与图片映射。
- `src/app`：首页、商品矩阵、ON 专区、正品说明、版本说明、防伪溯源、售后 FAQ、关于我们、联系我们及 SEO 路由。
- `public/assets`：真实品牌与商品素材；`optimized` 保存从项目复制件生成的网页压缩版本。
- `src/lib/site.ts`：正式域名与淘宝店跳转的统一配置入口。

官网不提供会员登录、订单认领、购物车或支付。所有购买与订单售后均转到淘宝店或对应淘宝订单处理。
